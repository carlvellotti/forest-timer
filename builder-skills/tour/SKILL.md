Give me a tour of my app as it is right now, as one page I can open in the browser.
I don't read code, so explain everything in plain words, and never make me read code to follow along. Ask me what I already know first, and pitch it at that level.
Redraw my app's architecture diagram from the code, and put it next to the diagram in my spec. Point out every difference.
Map the parts: each component's name, which screen it's on, and which ones hold data.
Show where my decisions landed: where the data is kept, where each rule from my spec lives, and whether every color and font comes from DESIGN.md.
End with a few questions that check I understand it, and let me answer them on the page.
Don't save the page in my project. I'll ask for a fresh one whenever I want it.
