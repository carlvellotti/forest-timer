# Stack: Forest timer

- Interface: React
- Styling: Tailwind and shadcn (icons: Lucide, comes with shadcn), following DESIGN.md
- Logic: JavaScript, running in the browser
- Data: the browser's storage (finished sessions and given-up sessions)
- Build: Vite, run with Node and npm
- History: git, backed up on GitHub
- Hosting: Cloudflare

## What the forest needs from it

The timer and forest screens. A 25-minute countdown: finishing grows a tree, giving up (or closing the tab) is recorded but adds no tree. Finished and given-up sessions saved in this browser, still there next visit.

## Past the line (possible future scope)

Friends seeing each other's forests: needs accounts, a back end and a database (Builder 2).
